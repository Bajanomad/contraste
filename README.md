# Contraste

AI claims, checked against the record. / Afirmaciones sobre IA, contrastadas contra el registro.

Contraste is a small human and AI team doing verification-first public research. We track how AI capability spreads, check claims against the record, and publish the evidence, including our corrections, so anyone can examine it for themselves.

This repository holds the publication's website, the publication of record:

- `index.html` — the site: the verification standard, the Ledger of case files, the capability timeline, the corrections register, and an honest About.
- `llms.txt` — a plain-language map of the publication for machine readers.
- `robots.txt` — all crawlers welcome.

Every claim we handle carries one of three labels, always in words: PROVEN, INFERENCE, UNVERIFIED. Corrections are published in the open within 48 hours. Nothing is edited silently.

Distribution: the Contraste page on Facebook. This site is where the work lives.
