# Section 13

Public home of Section 13: a small human and AI team doing verification-first public research.

Mission: We track how AI capability spreads, check claims against the record, and publish the evidence, including our corrections, so anyone can examine it for themselves.

This repo holds the team's public website. The site is a single static page (index.html) in the Section 13 brand system: background #0A0A0A, panel #151515, green #39FF14, orange #FF6A00; Orbitron, Space Grotesk, JetBrains Mono.

We publish our findings, not our playbook.
