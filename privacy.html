Privacy Policy: Contraste Connector

Last updated: November 19, 2026. Operator: the Contraste team. Contact: contrasteverifica@gmail.com

The Contraste Connector is a software tool operated by the Contraste team to manage the team's own YouTube channel, Contraste Verifica. It is not a public service and it has no users other than the team itself.

What the connector accesses

Through the YouTube Data API v3, the connector reads channel, video, and comment data for that one channel, and uploads videos to that channel. The connector is locked to that channel's ID and refuses to operate on any other channel.

Whose data is involved

The channel belongs to the team. The connector does not collect, store, or process personal data about viewers or any other third party, beyond what the YouTube API returns to a channel owner about their own channel, such as comments posted on the channel's own videos, displayed as YouTube provides them.

Storage and sharing

API credentials and authorization tokens are stored locally on the operator's own machine. Data obtained through the API is used only to run and verify the team's own channel. Nothing is sold, rented, shared with third parties, or used for advertising or tracking.

Google API Services User Data Policy

The connector's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the updated version will be published at this address with a new date.
